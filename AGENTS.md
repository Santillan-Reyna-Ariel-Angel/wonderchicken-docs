# Instrucciones para agentes: dónde escribirlas

- **`AGENTS.md` en la raíz del proyecto** (backend y frontend): lugar de las instrucciones para los agentes. Lo leen Claude Code, OpenCode y GitHub Copilot.
- **`.github/copilot-instructions.md`** aquí se pueden escribir instrucciones **para el agente de Copilot**. No repitas lo que ya está en `AGENTS.md`. Trarr de mantener 1 sola fuente de verdad
- **No crear un `CLAUDE.md`** salvo que sea necesario: Claude Code solo lee `AGENTS.md` cuando no existe ningún `CLAUDE.md`.
- **Rutas completas de los proyectos** (en esta máquina): backend `D:\SISTEMAS\wonderchicken-back`, frontend `D:\SISTEMAS\wonderchicken-front`.
